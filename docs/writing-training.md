## JSONとLessonへの対応

次は**形式説明用の例**です。実際のシートから取得した問題ではありません。

```json
{
  "id": "W-EC-TEST-001",
  "subject": "英C",
  "unitId": "7",
  "unitName": "1・2",
  "lesson": "7",
  "number": 1,
  "japanese": "私たちはごみを減らす必要がある。",
  "requiredExpressions": ["reduce"],
  "modelAnswer": "We need to reduce waste.",
  "acceptedAnswers": ["We have to reduce waste."],
  "hints": ["need to + 動詞の原形", "waste＝ごみ"],
  "explanation": "need to + 動詞の原形で必要性を表します。",
  "status": "公開"
}
```

英Cは既存教材の `id: "7"` に合わせて、単元IDだけをLessonキーとし、単元名「1・2」は各問題の上部にも表示します。論表は既存教材の `id: "12 不定詞(1)"` に合わせて、単元IDと単元名を半角スペースでつなぎます（13・不定詞(2)も同じ規則）。名称そのものはハードコードしません。

科目とLessonキーの両方で絞り込み、他科目・他Lessonの問題は混ぜません。既存4教材JSONと英作文JSONからLessonを集めます。問題のないLessonは無効です。教材側にない新しいLessonも英作文JSONから追加できます。各Lesson内は問題番号順、同番号ならID順です。旧JSONの `lesson` だけの形式も引き続き使用できます。

アプリの取得は `cache: no-store` です。シート編集→再同期→「問題を再読み込み」で更新します。Lesson画面を表示中なら件数と開始可否も更新します。進行中のセットは途中で差し替えず、再読込後にLessonを選び直す／再挑戦して新しい問題を開始してください。

## Apps Scriptへの追加と同期手順

1. 既存スクリプトをバックアップし、`apps-script/writing-sync.gs` を**別のスクリプトファイルとして追加**してください。既存関数・同期メニュー・トリガーは削除・置換しません。以前の版を追加済みなら、その英作文専用ファイルだけを更新します。
2. Script Propertiesに以下を設定します。秘密情報はチャットやGitHubに貼らないでください。

| プロパティ | 内容 |
| --- | --- |
| WRITING_SPREADSHEET_ID | 任意。省略時は上記の対象ID |
| WRITING_GITHUB_REPO | `f9-fish/Yoshi.Lab`（最初は検証用リポジトリを推奨） |
| WRITING_GITHUB_TOKEN | 対象リポジトリのContents書込権限に限定したトークン |
| WRITING_GITHUB_BRANCH | 最初は既存の検証用ブランチ名を指定。省略時は `main` |
| WRITING_ALLOW_EMPTY | 通常は未設定。公開問題を意図的に0件にする場合だけ `true` |

3. `previewWritingQuestions` を実行します。これはSheetsの読み取りだけを行い、GitHubへ書き込みません。実行ログの有効公開問題数・行番号付き警告・エラーを確認してください。現在リポジトリには公開20問があります。シート側の公開件数と一致するか管理者が確認してください。
4. エラーを修正して `syncWritingQuestions` を手動実行します。Sheetsの公開行→UTF-8のJSON→Base64→GitHub Contents APIの順で、指定ブランチの **writing_questions.jsonだけ**を更新します。トークンはログへ出しません。内容が同一ならコミットしません。既存ファイルのSHAを使い、競合・権限不足はエラーとして報告します。
5. 検証ブランチのJSON・アプリで確認後、通常のレビュー手順で公開します。`WRITING_GITHUB_BRANCH` を省略／mainに設定すると同期時にmainへ書き込みます。管理者が運用を確認したうえで設定してください。mainが保護されている場合はブランチへの同期とPRを使ってください。この作業ではmain書き込み・マージ・デプロイを実施していません。
6. 自動化する場合は、検証後に `syncWritingQuestions` **専用の時間主導トリガー**を管理者が追加してください。既存の英検・英C・論表トリガーは変更しません。初回のGoogle認可・トークン設定・トリガー設定は外部での未完了作業です。
7. 公開ページで英作文→科目→Lessonを選択し、日本語・指定語・ヒント・模範解答・別解・解説を確認します。問題を1つ編集／追加し、再同期→アプリ再読み込みで変更を確認してください。

## 判定・記録

大小文字、余分な空白、全角英数、文末記号、曲がったアポストロフィを正規化し、模範解答・許容解答と照合します。語順・時制・否定・単複を無条件には許容しません。

指定表現は単純な部分文字列でなく**単語境界・連続語**で確認します。原形 `go` と `goes` のような活用は機械的に同一視せず、指定表現の使用を確実に確認できない場合は「要確認」です。教材では、実際に使わせる表現を登録してください。登録外の正しい英文の可能性もあるため「不正解」と断定しません。AI採点・形態素解析はありません。

XPは0、ヒント使用による減点もありません。Firebase Rulesは未確認のため、英作文のクラウド保存・既存履歴への統合は引き続き未実装です。記録は画面内だけ保持し、JSONダウンロードで保存できます。新しい記録には `unitId`・`unitName` も含めます。英文・生徒IDを含むファイルは適切に管理してください。
