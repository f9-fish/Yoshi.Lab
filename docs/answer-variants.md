# 同じセルに別解を登録する

英C・論表の本文と単語で、同じ英語セルに別解を改行して入力できます。2個・3個以上でも、元の1セルを1問として扱います。同期済みJSONやApps Scriptの構成を変える必要はありません。

本文セルの例：

```text
I’m not so hungry. I don’t (feel) (like) (having) the steak.
I’m not so hungry. I don’t (feel) (like) (eating) the steak.
```

単語・熟語セルの例：

```text
attract
charm
fascinate
```

熟語も各行にひとまとまりで書きます。`to tell the truth` と `to be honest` などです。単なるスペース・カンマ・スラッシュでは別解に分割しません。

通常の改行、CRLF、`<br>` / `<br/>`、文字として保存された `\n` / `\r\n` を読み取ります。空行と重複行、セルに混入したゼロ幅文字を除きます。HTMLとして実行せず、意味の推測・自動翻訳は行いません。

本文は各行に英文全体を書き、解答箇所を `(答え)` にしてください。同じ問題の別解だけを同じセルに入れます。出題は先頭の英文だけを表示し、採点は登録された各行の答え全体と照合します。別々の行の答えを混ぜた組み合わせは正解にしません。

別解のある本文では、括弧内が熟語でも1つの欄に入力できます。別解によって語数・空欄数が違うときは、答えの語句を順番に1つの欄へまとめて入力することもできます。通常の1文だけの問題では、従来の単語ごとの入力欄を維持します。空欄が残り、登録された別解全体とも一致しないときは、入力を完了する案内を出します。

通常学習・Daily・ペアワークのタイピングで別解を認めます。単語4択の出題語や読み上げは先頭の語を使います。正答確認には他の登録語も表示します。既存の通常学習の同義語・文脈別の互換判定は、従来の単一解の問題で維持します。

正解数・学習記録・挑戦回数は1問分です。XP倍率・上限の互換処理、Dailyの回数制限・得点表は変更しません。英検の4択JSONの正解番号は変更しません。

共通処理は `answer-variants.js` です。`index.html` / `daily.html` / `pair.html` の採点処理より先に読み込みます。テストは本番に接続しない `tests/answer-variants.test.cjs` と既存テストを実行します。
