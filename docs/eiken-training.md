# 英検対策モード

## 実装とXP

- HOMEの「英検対策」から `eiken.html` へ移動し、準2級・2級を選択します。
- `eiken_pre2.json` / `eiken_2.json` を毎回取得し、形式が正しい問題から重複なしで最大10問を抽出します。問題数は固定しません。
- `answer` は1〜4です。配列を参照するときだけ1を引きます。`correctWord` と該当選択肢の一致も検証します。
- 0問なら「公開中の問題がありません」、10問未満なら実際の問題数と不足を表示します。通信失敗や不正形式とは区別します。
- 新しく開始する英検結果は`xpPolicyV2: true`を保存し、準2級1問5 XP・2級1問10 XPです。最大10問なので満点は50・100 XPです。過去の`eikenChoice`記録は両級1問5 XP・上限50、旧`xpMode: vocab`は1問1 XP・上限30を維持します。更新前の未保存セッションも元の倍率で保存します。
- 解答後に4つの選択肢すべての意味を語の横へ表示し、最後の振り返りにも表示します。解答前・次問への移動時には意味を表示しません。
- 終了ボタンで途中終了した場合も、解答済みの問題数・正解数と正解分のXPを保存します。0問は保存せず、未解答は不正解に数えません。新倍率の英検は5回目以降も途中終了分を加算し、通常学習の完答条件は変更しません。
- 共通XP計算・教員集計・過去シーズン集計を一致させています。通常学習も新規記録は単語4択1・単語入力7・本文タイピング10 XPで30 XP上限を撤廃しています。Daily・週間ボーナスは変更していません。
- XP同期成功後に、通常学習と同じデザインのXP獲得ポップアップを表示します。途中終了も対象です。保存・同期失敗中は獲得を確定表示せず、プロフィール未登録時は反映待ちを案内します。閉じる・背景クリック・Escapeで閉じられます。

## 選択肢の意味データ

同期JSONの `choiceMeanings` を選択肢と同じインデックスで読み取ります。正解かどうかにかかわらず、解答後と振り返りに4つすべてを表示します。日本語訳はJSONの文字列をそのまま使い、自動翻訳・推測・アプリ内辞書による補完はしません。
古いデータで項目がない場合、配列が短い場合、訳が空・文字列以外の場合は、その選択肢だけ「意味未登録」と表示します。問題の採点や出題可否には影響させません。
意味はtextContentで設定し、HTMLとして解釈しません。同期JSON・Apps Scriptはアプリ側では変更しません。
`eiken-training.js` 更新時は、`eiken.html` の読み込みURLのバージョンをファイルのSHA-256先頭12文字に更新してください。テストで一致を確認します。JSONは従来どおりcache:no-storeで取得するため、今後の訳追加だけならアプリ内辞書の更新は不要です。

## 保存・再試行

`account.js` に `saveEikenResult` を追加しています。Googleログイン済みかつメール確認済みの開始ユーザーだけが保存できます。

保存先は既存の `learningRecords/{uid}/eiken_{UUID}`。既存通常学習の `save()` は毎回pushキーを作るため、英検はセット固有UUIDと作成時トランザクションで保存します。応答喪失や同じ結果の再試行でも同じキーを使い、異なる得点による上書きを拒否します。XPは直接加算せず、既存 `syncXP()` で全履歴から再集計します。

保存するフィールドは既存形式です。

| 項目 | 値 |
| --- | --- |
| subject | 英検 |
| lesson | 準2級 または 2級 |
| part | 空所補充4択 |
| mode / xpMode | vocab / eikenChoice（旧記録のxpModeはvocab） |
| right / total | 解答済みの正解数 / 解答済み問題数（1〜10） |
| xpPolicyV2 | 新しく開始したセットはtrue。更新前の記録・未保存セットには追加しない |
| repeatPolicyV1 / completedSet | true / 全問解答ならtrue、途中終了ならfalse |
| bestStreak / durationSeconds | 最大連続正解数 / セット所要秒数 |
| createdAt / source | 保存時刻 / solo |

通常学習の既存キー・過去記録は変更しません。MY PAGEの教材一覧には、保存済みの英検記録から級・セットを追加します。

全問解答・途中終了の結果は保存前に、開始ユーザーのUID別で端末のsessionStorageへ一時保持します。同じタブの再読み込み後は「未保存の結果を確認する」から再試行できます。別ユーザーに保存しません。ゲストは問題・結果を確認できますが保存せず、ログイン後に新しいセットへ挑戦する案内を出します。

sessionStorageはタブを閉じると失われる場合があります。ブラウザーが保存を禁止した場合も端末保持できません。未保存の結果は画面を閉じる前に再試行してください。保存やXP同期がタイムアウトしても同じセットIDで再試行します。

## Firebase Security Rulesの確認事項（未適用）

リポジトリに本番Rulesがなく、現行権限は未確認です。ルール変更や本番アクセスは行っていません。既存形式を利用していますが、次を本番から隔離した環境で確認してください。

1. 確認済みGoogleユーザー本人が自分のレコードを読み取れ、`eiken_{UUID}` キーへ作成できること。トランザクションには対象ノードの読み取り権限も必要です。
2. 科目・Lesson・Partを列挙している場合、`英検`、`準2級` / `2級`、`空所補充4択` を許可対象に追加する必要があります。キーをpushキーだけに限定している場合は英検のUUID形式への対応も必要です。xpModeを列挙している場合は新しい `eikenChoice` の許可も必要です。
3. 正解数・出題数が整数、`1 <= total <= 10`、`0 <= right <= total`、`0 <= bestStreak <= right`、所要時間が非負、modeがvocab・xpModeがeikenChoice（旧記録はvocab）、completedSetが真偽値であることを検証してください。既存RulesがcompletedSetをtrueに限定している場合は、新倍率の英検に限りfalseも扱えるか確認が必要です。
4. 生徒が他人のレコードを読み書きできず、保存済みの英検結果を別の得点へ更新・削除できないことを確認してください。
5. 既存のプロフィール・leaderboard読み書きと `syncXP()` が許可されること。拒否時は画面にエラーを出し、記録保存とXP同期の成功を区別します。

新規の通常学習・英検は`xpPolicyV2: true`という真偽値を保存します。未知のフィールドを拒否するRulesの場合は、このフィールドの許可が必要か隔離環境で確認してください。今回Rulesは変更していません。

これはルールの緩和指示ではありません。現行Rulesを確認したうえで、必要な差分のみユーザー承認の対象としてください。
クライアント採点は改ざん防止の根拠にはなりません。サーバーによる採点の正当性確認は既存アプリと同様に未実装で、今回のローカルテストでも本番Rulesの安全性は保証しません。

## 検証

```sh
node --test --test-isolation=none tests/*.test.cjs
```

`tests/eiken.test.cjs` は実データ形式、正解番号、ランダム抽出、0問・少数問題、全問振り返り、ゲスト、途中終了、保存再試行と二重加算防止を架空のFirebaseで検証します。
Googleログイン・本番Rules・実際のランキング反映は本番に接続せず、承認された検証環境で別途確認が必要です。

途中終了分の保存は画面内の「途中で終了する」ボタンで行います。タブを閉じる・再読み込み・HOMEへ直接移動しただけでは自動保存しません。途中退出の前に終了ボタンで結果画面へ進んでください。
