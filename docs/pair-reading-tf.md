# ペアワークの本文正誤問題

英C → 学習内容に「本文正誤問題」を追加します。既存Reading Plusの `extension_questions.json` から、公開・英C・True / Falseの有効な問題だけを取得します。現在はLesson 8 / Part 1の4問。Discussionや非公開・不正な答え・重複IDは出題せず、デモ問題で補完しません。Reading Plus画面・教材JSON・Apps Scriptは変更しません。

## 使い方

英C → 本文正誤問題 → Lesson → Part → 時間設定 → 6桁参加コード → 交代設定 → 役割確認 → 開始。

両端末に英文を表示し、回答者はTrue / Falseで口頭回答、出題者が○正解・×不正解で判定します。出題者には正解・解説を表示し、回答者画面では判定後に表示します。判定後は出題者が次へ進めます。既存の半分・1問・2問交代、タイマー、正解数、STREAK、結果とHome遷移を再利用します。論表には追加せず、ペアワークへのXP付与は追加しません。

作成時の問題を `rooms/{code}/tfQuestions` として固定するため、途中の教材同期や参加側の教材が空になっても問題セットは変わりません。`mode: textTF` で通常モードと区別します。接続と再参加の仕様は既存通常ペアを引き継ぎます。

## デザイン

`pair-menu.css` は選択画面に限定して適用します。ネイビーの枠・緩やかなグラデーション・線画アイコンで統一し、本文穴埋めは青、単語は金、Q&Aは紫、正誤はミントのアクセント。PCは2列、携帯は縦並び。参加コード欄・戻るボタンも統一します。ゲーム中のパネルと既存背景は維持します。

## 権限と確認の範囲

リポジトリのユーザー提供Rulesには、通常ルームの作成、参加者の読み取り、出題者による判定・進行の条件があります。この方式に新しいRules変更は追加していません。現在本番で適用中のRulesは未確認です。

通常ペアと同様、ルームを読める参加者には答えを含むデータが届きます。回答者画面の正解非表示はUIの制御であり、開発者ツールでの閲覧防止を保証しません。元の教材JSONも公開教材です。問題内容や口頭採点の真偽をサーバーで検証する方式ではありません。
