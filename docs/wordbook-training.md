## 管理するシートと列

新しい単語帳専用スプレッドシートのSTAGE0〜3を、そのまま使用します。既存の英C・論表・英検等のシートや同期コードは変更しません。

元の9列：`Unit / 見出番号 / 見出語 / 見出語日本語 / フレーズ / フレーズ日本語 / 例文 / 例文日本語 / 活用`。

追加できる任意列：

| 列 | 内容 |
| --- | --- |
| 出題用日本語 | 4択・スペリングで表示する短い日本語。空欄なら元の訳の最初の行から品詞ラベル等を除いて使用 |
| スペリング別解 | 許容する別表記を改行または `||` で登録。無条件の活用形変換はしない |
| 並び替え対象 | `使用` で対象、その他の非空欄は対象外。空欄は単文・2〜32語句の例文のみ自動選択 |
| 並び替え別解 | 同じ語句で作れる別の英文を改行または `||` で登録 |
| 公開状態 | 列自体がない旧形式では対象範囲内を公開。列を追加した後は見出語行が `公開` の単語のみ出力。続き行の空欄は親の状態を引き継ぐ |

見出語・番号のない続き行は、直前の見出語の追加例文です。別の単語として数えません。`_x000D_` は削除し、改行は保持します。元の日本語訳・例文・フレーズ・活用はデータに残します。IDはSTAGE・Unit・見出番号を組み合わせ、同じUnit内の番号重複はエラーにします。

## スプレッドシート側で次にすること

1. スプレッドシートで「拡張機能 → Apps Script」を開きます。既存の関数・トリガーがあれば削除しません。
2. ファイルを2つ追加します。`WordbookData.gs` にリポジトリの **wordbook-data.js全文**、`WordbookSync.gs` に **apps-script/wordbook-sync.gs全文**をコピーして保存します。共通変換ロジックをブラウザーと同期で共用しています。
3. 関数 `previewWordbook` を選び実行します。Googleの承認画面が出たら、対象シートを読むための権限を確認します。この関数はGitHubへの書き込みやトリガー登録をしません。
4. まずログを確認します。添付Excelと同じ内容なら「対象：STAGE1:Unit1／公開単語：11語／例文：11件／警告：1件／エラー：0件」を想定します。番号重複の警告はSTAGE3の元データに由来します。実シートが編集されていれば件数は変わります。
5. エラーがあれば同期せず内容を確認します。トークンや認証情報はチャットへ貼らず、実行結果の件数・警告・エラーだけ共有してください。

### プレビュー確認後のGitHub同期設定

Apps Scriptの「プロジェクトの設定 → スクリプト プロパティ」に設定します。

| プロパティ | 値 |
| --- | --- |
| WORDBOOK_SPREADSHEET_ID | 上記ID。省略しても上記IDを使用 |
| WORDBOOK_GITHUB_REPO | `f9-fish/Yoshi.Lab` |
| WORDBOOK_GITHUB_TOKEN | 管理者のGitHubトークン。Script Propertiesだけへ保存。Contentsの必要最小限の権限 |
| WORDBOOK_GITHUB_BRANCH | 最初はレビュー用の `feat/wordbook-training-pilot`。未作成ブランチは自動作成しない |
| WORDBOOK_SCOPE | 初期値・省略時は `ALL`。全件反映は `ALL`。すでに `STAGE1:Unit1` を設定済みの場合は、明示的に `ALL` へ変更が必要 |
| WORDBOOK_ALLOW_EMPTY | 通常は未設定。意図してJSONを空にする場合だけ `true` |

`syncWordbook` を手動実行すると、指定ブランチの `wordbook.json` だけを更新します。既存JSONと同じなら書き込まず、SHAを使って同時更新の競合を検出します。エラーや意図しない0件は既存JSONを保持します。初期の試作JSONはExcel由来のメタデータなので、最初の同期では出典も更新されます。自動実行トリガーは追加していません。`main` へ直接書く同期は、レビュー用ブランチでの確認後に管理者がブランチ設定を変更して行う別の操作です。

同期後、アプリの「問題を再読み込み」で取得し直します。クイズ中のセットは固定し、途中でシートが更新されても差し替えません。

## 採点と既存機能への影響

- 4択は異なる英語と異なる出題用日本語から4つ作れた問題だけを出題します。4つ作れない場合、開始できません。別解と同じ語を誤答候補にしません。ただし意味の近い語まで機械的に完全排除したとは扱わず、教師による出題用日本語・候補の確認が必要です。
- スペリングはNFKC・大文字小文字・余分な空白・曲がったアポストロフィを正規化します。否定や文字の欠落は許容しません。明示的な別解のみ追加で認めます。
- 並び替えは同じ単語が複数あっても各ボタンを独立して扱います。選択を戻す・リセットできます。語順を照合し、文末記号等の軽微な差を正規化します。
- 解答後に正解・元の訳・例文を表示し、4択は4つの意味も表示します。すべてtextContent等で挿入し、教材をHTMLとして解釈しません。
- この試作はXP付与・Firebaseへの学習履歴保存を行いません。結果は画面内だけです。Firebase SDKや認証状態を操作せず、既存のログイン・XP・Daily・ランキング・通常学習・ペア・教員画面のコードは変更しません。
- HOMEは既存科目と同じグリッド内に単語帳カードを追加しました。広いPCでは5枚を横並び、狭いPCでは2列、スマートフォンでは既存カードと同じ縦並びにします。背景・共通ナビゲーション・ダークネイビーのパネルを再利用します。
